# EVE-Blog

Der Blog lässt Menschen möglichst unmittelbar an den Gesprächen teilhaben, aus denen EVE entstanden ist.

Das Projektlog verdichtet und ordnet. Der Blog macht fast das Gegenteil: Er bewahrt Stimmen, spontane Umwege, Originalformulierungen und den Moment, in dem aus einem Witz plötzlich eine brauchbare Hypothese wurde. Die Beiträge sind deshalb redaktionell geschnittene Gesprächserzählungen und keine nachträglich geglätteten Projektberichte.

## Leseschlüssel

Jeder Beitrag nennt direkt am Anfang seinen redaktionellen Status. Zusätzliche Randnotizen erscheinen nur dort, wo eine Aussage leicht stärker wirken könnte, als sie belegt ist:

- **Beobachtung:** tatsächlich gemessen oder am Projekt erlebt
- **Hypothese:** prüfbare Erwartung vor einem Ergebnis
- **Interpretation:** unsere Deutung einer Beobachtung oder eines Zusammenhangs
- **Spekulation:** theoretisch mögliches oder weit entferntes Szenario
- **Hirnschiss:** wilde Idee mit möglichem ernstem Kern
- **Designentscheidung:** eine von uns gesetzte oder geplante Regel für EVE

Eine Kennzeichnung gilt für die unmittelbar zugehörige Passage. Der restliche Dialog darf weiterhin wie ein Gespräch klingen.
